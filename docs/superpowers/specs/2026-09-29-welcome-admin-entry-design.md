# 웰컴 화면 관리자 진입 설계

## 목표

로고를 숨겨도 운영자가 웰컴 화면에서 관리자 로그인으로 진입할 수 있게 하고, 빈 안내 문구도 저장할 수 있게 한다.

## 동작

- 로고가 보이면 기존처럼 로고를 0.8초 길게 눌러 관리자 로그인으로 이동한다.
- 로고 표시 여부와 무관하게, 웰컴 화면 우측 하단의 보이지 않는 작은 영역을 0.8초 길게 누르면 같은 로그인 화면으로 이동한다.
- 짧게 누르거나 누르는 도중 포인터가 영역 밖으로 나가면 이동하지 않는다.
- 안내 문구는 빈 문자열을 허용하며, 고객 웰컴 화면에서는 문구 영역을 비워 둔다.

## 범위

변경 대상은 웰컴 화면 UI와 공유 설정 계약, 그에 대한 단위 테스트뿐이다. 관리자 인증 방식, 화면 배치, 기존 로고 진입 동작은 바꾸지 않는다.
