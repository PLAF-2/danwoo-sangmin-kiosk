# Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the protected local HIGHEST administrator UI for catalog, media, welcome, payment, password, and atomic backup management.

**Architecture:** Reuse the Foundation IPC and Zod contracts. A renderer-only admin session provider owns routing and the five-minute input timer, while a small authenticated keep-alive IPC keeps the main-process session aligned with real operator activity. Route pages read fresh data on entry and save whole validated documents through the existing atomic stores.

**Tech Stack:** React 19, React Router 7, TypeScript, Zod, Electron IPC, Vitest, React Testing Library, CSS
